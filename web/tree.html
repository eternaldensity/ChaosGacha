How to play

1. 🌳 The Origin root (sphere centre) is free and already unlocked.
2. 🎟 Award tickets (Tickets tab) — each gives 1 core + points for a shared wallet.
3. 🔓 Unlock frontier nodes next to yours (1 core + points each; ⬡ marks affordable ones).
4. 🎫 Special tickets (skip / jump / hop) reach distant nodes.
5. ✨ Unlock tree-meta nodes (Sight, Graft, Chaos Die…) for powers.
6. 💾 Progress saves automatically; export backups from below.
